# Contributing

Make small, evidence-backed changes. Preserve working comma segmentation and
interruption behavior. Run scripts/Check.ps1 on Windows. Tests must not need real
keys, paid services, private paths, virtual drivers or the old project.

For device fixes report what was actually heard, the browser, devices and trace.
Compilation, a live track and received PCM alone do not establish audible output.
Do not bundle settings, logs, build outputs or old backups. Build candidates in
artifacts without overwriting a working installation. Keep Beta labels until the
acceptance matrix in docs/ACCEPTANCE.md is complete.
