# VoiceBridge 详细使用指南

[返回首页](../README.md) · [使用场景](USE_CASES.md) · [下载 0.3.0 Beta](https://github.com/yaokon6868/VoiceBridge/releases/tag/v0.3.0-beta)

本指南首先面向 **公开发布的 0.3.0 Beta**。0.3.1 候选版使用不同启动方式和配置目录，单独放在文末说明，不能把两者的步骤混用。

## 1. 安装前准备

| 项目 | 需要什么 |
|---|---|
| 电脑 | Windows 11 x64；能正常收音、播放声音 |
| 浏览器 | Chrome；允许手动加载扩展 |
| ChatGPT | 已登录且可使用 Voice；确认原始语音对话先能正常工作 |
| Fish Audio | 自己的 API Key，以及选定音色的 Voice / Reference ID |
| 网络 | 可访问 ChatGPT 和 Fish Audio 服务 |
| 声音设备 | 首次测试建议耳机；0.3.0 外放回声尚未解决 |

不需要编程环境、额外的 .NET 安装或启动 Fish PWA。公开版不需要 VB-CABLE；不要为了试用 0.3.0 把麦克风改成 CABLE Output。

## 2. 下载并安装桌面程序

1. 打开 [0.3.0 Beta 发布页](https://github.com/yaokon6868/VoiceBridge/releases/tag/v0.3.0-beta)。
2. 展开 **Assets**，下载 `VoiceBridge-Windows-x64.zip`。`VoiceBridge-Source.zip` 和 GitHub 自动生成的 Source code 是源码，不是安装包。
3. 在下载文件上右键 → **全部提取**。不要在 ZIP 压缩预览窗口中直接运行安装。
4. 进入解压后的文件夹，确认能看到 `Install.cmd` 以及 `app`、`extension`、`scripts` 等目录。
5. 双击 `Install.cmd`。安装器默认不需要管理员权限；完成后会显示安装路径，并创建桌面 **启动换声工具**。
6. 安装器通常会启动程序。以后双击桌面入口即可；不要连续打开不同文件夹里的旧 EXE。

默认安装位置：

```text
%LOCALAPPDATA%\VoiceBridge
```

在普通 Windows 桌面上，按 **Win + R**，粘贴上述路径并回车即可查找。若使用自定义安装位置，或通过打包应用环境安装导致目录被重定向，以安装器实际输出和快捷方式目标为准，不要照抄维护者电脑的绝对路径。

## 3. 安装 Chrome 扩展

桌面程序和扩展各负责一部分：扩展读取网页助手文字；桌面程序显示字幕、请求合成并播放。只装其中一项不能完成网页换声。

1. Chrome 地址栏输入 `chrome://extensions`，回车。
2. 开启页面上的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**。
4. 选择安装目录中的 **extension 文件夹**，默认是 `%LOCALAPPDATA%\VoiceBridge\extension`。不要选择 ZIP 或整个 VoiceBridge 根目录。
5. 确认 VoiceBridge 扩展已启用。旧版 VoiceBridge 扩展先停用，只保留一个。
6. 在 Chrome 工具栏的拼图菜单中找到 VoiceBridge，可把它固定到工具栏，方便检查状态。
7. 刷新已经打开的 ChatGPT 页面。安装/更新扩展前已打开的页面可能仍使用旧脚本。

扩展名称可能包含 **VoiceBridge Next**；这里的 Next 是名称，不代表已经安装 0.3.1。版本以扩展管理页和发布包为准。

## 4. 创建 Fish Key 并选音色

### API Key：用于认证

1. 登录 [Fish Audio API Keys 页面](https://fish.audio/app/api-keys)。
2. 选择创建新 Key，为它取一个容易识别的名称，例如 `VoiceBridge`。
3. 复制生成的 Key，填到本机 VoiceBridge 设置的 **API Key** 栏。
4. 不要把 Key 填到 Voice ID 栏，不要发到 Issue、聊天截图或仓库文件里。

免费模型仍需要账号认证，免费不等于免 Key。当前免费入口不要求绑卡；若页面出现充值要求、额度或模型错误，先核对 [免费模型政策](https://fish.audio/blog/s2-1-pro-free-api/)，不要为了排查自动改用付费模型。免费期限和服务条件见首页。

### Voice / Reference ID：用于选择声音

1. 在 [Fish Audio](https://fish.audio/) 找到一个你有权使用、可以访问的音色，先试听确认。
2. 打开该音色详情页，使用复制模型 ID 的按钮；也可按 [官方 Quick Start](https://docs.fish.audio/developer-guide/getting-started/quickstart) 从音色页面 URL 中取得模型 ID。
3. 在类似 `https://fish.audio/m/<模型ID>` 的地址中，填写的是 `<模型ID>`，不是整条网址、音色显示名称或账号名称。
4. 将它填入 VoiceBridge 的 **Voice / Reference ID** 栏。

API Key 和音色 ID 是两项独立内容。仅在 Fish 网页上选中音色，不会自动同步到 VoiceBridge。

### 保存到 VoiceBridge

1. 找到右下角 VoiceBridge 托盘图标；隐藏时点击任务栏旁的 **∧**。
2. 双击图标，或右键 → **设置与外观**。
3. 填好 Key 和音色 ID，勾选 **启用 Fish Audio 流式朗读**。
4. 模型栏保持 `s2.1-pro-free`；它由程序固定。
5. 点击 **保存设置**。若出现保存失败提示，保留当前窗口内容，先解决保存问题。
6. 再打开设置核对朗读开关和音色 ID；无需重复创建 Key。

只想使用字幕时可以关闭 Fish 朗读。字幕采集本身不依赖 Fish Key，但仍需要桌面程序和网页扩展接通。

## 5. 完成第一次网页测试

1. 先戴耳机，确认 VoiceBridge 已在托盘运行。
2. 刷新 `chatgpt.com` 的对话页，允许浏览器使用真实麦克风。
3. 开启 **ChatGPT 语音对话**，不是普通输入框旁的语音听写，也不是点击某条旧回复的朗读按钮。
4. 说一句简单的新问题，例如“你好，请用两句话介绍你能做什么”。
5. 检查以下三个结果：字幕出现新的助手回复；听到选择的 Fish 音色；扩展弹窗显示网页/语音连接信息。
6. 再问一个稍长的问题，检查回复是否完整、是否重复。用说话打断测试取消效果；客户端识别和实际延迟仍可能因环境不同而变化。

字幕会随文字更新；朗读按逗号或短语缓冲，可能稍晚于字幕，不会刻意等整轮文字都完成。字幕预览只证明窗口能显示，不证明网页采集或 Fish 已接通。

扩展中的状态可这样理解：

| 现象或状态 | 含义与下一步 |
|---|---|
| 本机服务没有接通、未连接 | 先启动桌面程序，再检查是否启用同一安装包的扩展 |
| 本机服务正常，但未收到网页心跳 | 刷新 ChatGPT，或点“重新接入已打开的 ChatGPT 网页” |
| 网页已接通，尚未检测到正在进行的语音 | 确认打开的是语音对话，并说一句新话 |
| 语音已检测、文本事件增加 | 文字进入扩展；若有字幕但无声音，再检查 Fish 配置和声音输出 |
| 换声暂停 | 看暂停原因，处理后从托盘“重试 Fish 换声”；不能只靠重载页面判断恢复 |
| 播放 idle | 可能只是当前没有朗读；结合语音状态和新回复判断，不单看这一项 |

## 6. 日常启动、调整字幕和退出

### 启动与设置

双击桌面 **启动换声工具**，从托盘打开设置。关闭设置窗口只是关闭设置，不是退出后台程序。

公开版安装后，主程序默认在安装目录的 `app\VoiceBridge.Next.exe`。若桌面入口丢失，可在原完整安装包重新执行 `Install.cmd` 创建入口。候选版的 EXE 不能照搬这个直接启动办法，见文末。

### 字幕外观

1. 托盘右键 → **调整字幕位置**，暂时关闭鼠标穿透。
2. 拖动字幕窗调整位置，从右下角调整大小。
3. 在 **设置与外观** 调整字号、文字不透明度和背景不透明度。
4. 调整完成后重新勾选 **鼠标穿透**，点击保存；此时鼠标会穿过字幕窗，不能直接拖动它。

“不透明度”越高越实，背景调低会更透明；文字和背景分开调整。位置和外观会保存。托盘的 **显示字幕窗** 用于预览，**隐藏字幕窗** 用于暂时隐藏，新的采集事件可能再更新显示状态。

### 停止与退出

- **停止当前朗读**：停止 Fish 当前播放，不是结束 ChatGPT 语音，也不是关闭整个工具。
- **退出 VoiceBridge**：从托盘右键菜单退出，检查字幕窗和托盘图标消失。
- 结束 ChatGPT Voice：在网页关闭语音对话；这不会卸载 VoiceBridge。

若退出后明显卡住，先结束网页语音，核对任务管理器里的 `VoiceBridge.Next.exe` 路径，再处理该工具的残留进程。不要结束 Chrome、Codex 或其他无关程序来碰运气。

## 7. 普通版与隔离版 Codex

两个入口都在目标范围内，但属于 **Beta 桌面兼容性功能**，需分别测试。网页扩展不能代替桌面采集，也不会自动替你设置 Codex 的麦克风。

1. VoiceBridge 设置中勾选 **监听普通版和隔离版 Codex 桌面**，保存。
2. 托盘右键 → **接入普通版和隔离版 Codex**。公开版仅勾选设置不等于已启动采集。
3. 打开其中一个 Codex 的语音聊天，说一句新问题，检查助手回复文字、字幕和 Fish 声音。
4. 关闭这次语音，再到另一个 Codex 重复测试；第一次不要同时让网页和两套桌面客户端说话。
5. 若无字幕或出现原声与 Fish 双重播放，记录是普通版还是隔离版，不要把另一入口的成功当作此入口已接通。

重启公开版后可再次使用托盘接入。开发者也可用 `--desktop` 启动桌面采集。桌面读取依赖客户端可访问的语音界面文字；不保证普通打字回复、隐藏界面或每次客户端更新都能被正确读取。

## 8. 按症状排查

| 问题 | 优先检查 |
|---|---|
| 双击后没有大窗口 | 看右下角托盘/隐藏图标；打开设置，不要连续启动多个版本 |
| 找不到安装文件夹 | 以安装器输出、快捷方式“属性”的目标为准；不要使用别人电脑的路径 |
| 程序确实未启动 | 核对完整解压、`app` 文件夹、安装错误提示；记录具体提示 |
| 没字幕也没换声 | 先看扩展连接、网页心跳和是否真的开启 Voice；再检查 Fish |
| 只有“字幕预览” | 这是预览窗口，需收到新的助手文字才代表采集成功 |
| 讲话后 ChatGPT 没有文字或回复 | 先恢复 ChatGPT 收音权限及真实麦克风；这是输入链路问题，不是音色 ID 问题 |
| 0.3.0 选择 CABLE Output 后听不到人声 | 切回真实麦克风，退出并重开网页语音；公开包没有虚拟麦克风处理器 |
| 有字幕但没有 Fish 声音 | 朗读开关、保存的 Key/音色 ID、Windows 声音输出和应用音量，最后重试 Fish |
| 只听到官方声音 | 可能未接管或合成已回退；检查字幕、扩展连接和暂停原因 |
| 官方声音与 Fish 都在说 | 核对单一客户端/扩展版本，记录入口与出现时机；当前 Beta 不承诺所有客户端原声抑制都可靠 |
| 回复被当成用户的话、自问自答 | 外放回声；公开版先用耳机，候选版按 AEC 专项检查，不用文本去重代替回声消除 |
| 只读第一句、漏读、复读或卡顿 | 记录新一轮触发方式、客户端/扩展版本、是否打断及网络状态，提交可复现问题 |
| 更换设备后无声 | 核对 Windows 输出和网页实际输入，再重新开启语音；候选版还需检查实际设备设置 |
| 升级后未连接或认证错误 | 只保留一份扩展，重新加载扩展并刷新网页；桌面程序与扩展一起升级 |

遇到 Fish 错误时：401 通常应核对 Key；400 需核对音色 ID/参数；429 需等待后重试。不要把扩展连接认证错误和 Fish Key 错误混为一谈；免费模型异常时先核对其当前政策，不以充值作为默认修复步骤。

## 9. 升级、开机启动与卸载

### 升级

1. 先结束正在进行的语音，从托盘退出旧版。
2. 下载并完整解压新版本 Windows 包，运行它的 `Install.cmd`。
3. 在 Chrome 扩展管理页重新加载对应扩展，停用旧副本。
4. 刷新 ChatGPT，重新开启 Voice，用一句新回复验证字幕和完整朗读。

修改 README 或拉取 GitHub 源码不会自动升级本机程序。升级失败时保留旧安装包和配置备份，反馈具体版本及错误，不要同时运行两版。

### 开机启动（可选）

在解压包所在文件夹打开终端，执行：

```powershell
.\Install.cmd -StartWithWindows
```

重新执行普通 `Install.cmd` 会移除该安装创建的开机启动项。这个入口属于公开版安装器，不是候选 AEC 启动器。

### 卸载与设置

默认安装可从安装目录运行 `Uninstall.cmd`，再到 Chrome 扩展管理页移除 VoiceBridge。当前卸载器只接受默认的 `%LOCALAPPDATA%\VoiceBridge` 安装根；开发者若使用自定义 `InstallRoot`，脚本可能拒绝卸载。此时先退出程序，核对 VoiceBridge 专用安装目录和快捷方式，再手动移除对应安装文件、入口和扩展，保留个人设置。默认设置保存在：

```text
%USERPROFILE%\.voicebridge-next\settings.json
```

升级、卸载通常保留设置；需要彻底清除时先确认该目录仅属于 VoiceBridge。Key 用当前 Windows 用户 DPAPI 加密，换电脑或 Windows 用户后需要重新填写，不能直接复制配置当作可用密钥。

## 10. 0.3.1 候选版：不要混用启动方式

截至 2026-10-09，0.3.1 尚无公开候选安装包。下面用于参与源码构建和专门候选测试的用户，不是 0.3.0 安装步骤。

- 使用包含 AEC 处理器的完整候选包，并另外安装官方 VB-CABLE 驱动。构建方法见 [AEC-031.md](AEC-031.md)。
- 先保存设置、结束语音并退出旧实例。在完整候选包根目录打开 PowerShell，通过包内 `.\scripts\StartCandidate.ps1 -EchoCancellation` 启动。当前公开源码的启动器传入 `--candidate --echo-cancel`；桌面采集还需从托盘开启。不要在 0.3.0 包里寻找这个脚本，也不要从候选 EXE 随手创建无参数快捷方式，以免读到另一份配置或漏掉回声处理。
- 候选设置独立保存在 `%USERPROFILE%\.voicebridge-next-candidate`。文件放在名为 Candidate 的目录里，不代表它会自动使用候选配置。
- 设置里选择真实麦克风和实际扬声器。`CABLE Input` 是向虚拟线缆送入声音的一端，客户端收音选择的是 `CABLE Output`，不要反过来。
- 先确认回声组件正常并确实输出麦克风声音，之后才验证网页/桌面客户端的虚拟输入。仅看 `aecReady=true` 不证明客户端正在收听它。
- 网页在组件就绪后退出并重新开启 Voice，检查扩展显示的实际输入；Codex 桌面设备接入需要单独核验。
- 安静时连续外放三轮，中途用人声打断，再检查全文朗读、无自问自答、退出恢复和重新启动。

所有版本均不捆绑虚拟音频驱动。候选功能尚未全面验收，处理失败时先恢复真实麦克风。不要通过关闭麦克风来冒充“保留语音打断”的回声修复。

## 11. 反馈问题时提供什么

在 [Issues](https://github.com/yaokon6868/VoiceBridge/issues) 说明：

- Windows 版本、桌面程序版本、扩展版本；是否使用候选包。
- 入口：ChatGPT 网页、普通版 Codex 或隔离版 Codex。
- 设备：耳机还是扬声器、实际麦克风名称、是否使用 VB-CABLE。
- 复现步骤、预期结果、实际结果，以及发生前是否升级/切换设备/打断。
- 脱敏后的扩展状态或错误截图。

不要上传 API Key、设置文件、包含私人聊天内容的原始截图或未经检查的日志。诊断元数据也可能含设备名称和时间。隐私与本机连接机制详见 [SECURITY.md](../SECURITY.md)。
