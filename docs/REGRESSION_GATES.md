# 修复记录与打包门槛

`scripts/Package.ps1` 必须先运行 `scripts/Check.ps1`；检查失败即停止打包。
模拟检查通过后，仍须区分本机真实验收，不把返回音频字节当作用户听到完整回复。

| 已发生的问题 | 责任模块与回归检查 | 本机验收 |
| --- | --- | --- |
| 只读标题或第一句，正文丢失 | 桌面树读取、会话状态、文本管线组合；多段正文、粗体拆分、标点修订 | 对照完整长回复与已送文字 |
| 控件短暂消失被当成关闭 | 桌面会话状态；按实际约 1.3 秒缺失重放，不发 stop/interrupt | 保持语音开启观察重建 |
| 历史条目数量变化造成误打断 | 用户消息身份与发言角色；全树角色数变化不清空游标 | 滚动与控件重排时不断句 |
| 工具计时变化被误认为用户新发言 | 实测消息树的时间戳边界；排除正文外状态，保留正文内时间 | 语音回复期间身份不随计时变化 |
| 动态 UIA 树缓存中途失效 | 缓存重试一次，失败保留当前正文游标 | 界面变化时不复读、不立即释放原声 |
| 已读文字复读 | 快照去重、相同回复的新轮次、重复 complete 合并 | 同一回复只读一次，新轮次可重复回答 |
| 已读前文增删导致未读尾部错位 | 快照游标映射；插入、删除、跨边界修改、逗号修订不吞负号 | 按首/中/末检查点确认整段只读一次 |
| 活动入口交错导致同一回复反复接管 | 被接替会话退役；迟到正文与重复 start 不抢回，新 SessionId 可接管 | 网页与两个 Codex 各三轮；旧会话不重新朗读 |
| 系统原声先播，再播 Fish | 独立的原声静音状态；语音激活提前静音，普通轮次打断不恢复 | 每轮只有 Fish 音色 |
| 虚拟麦克风无声 | AEC 就绪与输入路由检查；本机 CABLE Output 采集验证 | 换声期间可讲话与打断 |
| 外放回声变成用户输入 | AEC 与输入路由门禁；合成信号检查不代替真人外放验证 | 三轮外放无自问自答，真人可打断 |
| 退出卡住、服务停而进程未退出 | Bridge 生命周期；非泵消息 UI 上下文与真实 WebSocket 退出检查 | 安装后的启动入口正常退出并重启 |
| 启停仍要求用户清理任务管理器 | 关闭入口认证正常退出，等待主程序和所属 AEC；与启动共用互斥 | 实际关闭 .lnk 返回0、主/子进程退出、端口释放，再由自启入口恢复 |
| 快捷方式没有可见反馈、重复点击重启 | 原生设置请求的认证检查、启动互斥与健康实例复用 | 用桌面 .lnk 连续启动两次，窗口出现、PID 不变、主程序和 AEC 各一份 |
| 开机自启仍启动旧版且漏桌面采集参数 | 自启与桌面入口统一；自启后台模式复用健康实例 | 检查 Startup 的目标与参数，执行后 PID 不变 |
| 两个客户端互相打断 | SessionRouter；未发言的客户端不能取消当前回复 | 普通/隔离版分别测试 |
| 免费模型误用付费默认值 | Transport；每次握手固定模型，无付费回退 | 仅 s2.1-pro-free |

当前桌面控件缺失采用 2 秒确认窗口，在这期间保留同一回复游标和原声接管；
不把不完整界面帧当作正文删除。持续缺失或真实关闭后停止，释放原声。
正文内容不写入运行日志，诊断只保留长度、次数、状态和时间。
